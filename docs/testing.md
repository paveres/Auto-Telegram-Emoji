# Проверки

Перед публикацией пройдены 38 автоматических тестов на Windows с Python 3.11. Проверен настоящий рендер трёх шаблонов сокращённого каталога с разными надписями: созданы изображение, MP4 и три TGS без сетевых запросов.

Оплаченный заказ FunPay и публикация пака через Telegram на личных данных в этой сборке не выполнялись. Linux установка подготовлена, но на отдельном Linux сервере не проверялась.

Запуск автоматических тестов:

```bash
python -m unittest discover -s tests
```

Тесты проверяют распознавание метки в последней строке, оплату и владельца заказа, повторные события, бонусы, сохранение этапов, выбор текстов, паки и ограничение доступа к панели.

Проверка кода перед публикацией:

```bash
python scripts/check_release.py
```

Создание публичного архива:

```bash
python scripts/build_release.py
```

Архив создаётся в `dist`. В него не попадают `.env`, рабочая база, импортированные коллекции и виртуальное окружение.

Автоматические проверки выполняются без личных данных и без реальных покупок. Они не заменяют тест оплаченного заказа на вашем аккаунте FunPay.
