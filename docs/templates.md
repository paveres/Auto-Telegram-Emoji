# Шаблоны

Программа меняет векторные контуры надписи в подготовленных TGS. Она не распознаёт текст внутри произвольной анимации.

Редактируемые элементы должны быть путями Lottie с именами `emoji_glyph:...`. Демо в `assets/tgs/classic` показывает формат. Для замены используются контуры шрифта, а не текстовые слои Telegram.

## Папка импорта

```text
Мои шаблоны/
    classic/
        1.tgs
        2.tgs
    love/
        1.tgs
    characters/
        1.tgs
```

Поддерживаются имена коллекций `characters`, `classic`, `finance`, `gift`, `love`, `one`, `other`.

Выберите родительскую папку в мастере. Шаблоны проверяются перед импортом. В рабочем проекте они хранятся в `data/assets` и не включаются в публичный архив.

В каждой коллекции оставлено не больше 25 шаблонов. Дополнительные шаблоны подключаются через мастер. Шрифты распространяются с OFL лицензиями.
