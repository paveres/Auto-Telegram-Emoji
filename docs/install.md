# Установка

## 1. Подготовка

Нужен Python 3.11, аккаунт FunPay со счётом в рублях, Telegram бот от @BotFather и ваш числовой Telegram ID.

Купите домен или получите бесплатный.

## 2. Windows

Распакуйте проект в отдельную папку. Запустите `install.bat`. Дождитесь установки библиотек.

Мастер запросит golden_key, токен бота, ваш Telegram ID, адрес предпросмотра и тарифы. Секреты вводятся скрыто и сохраняются локально.

После настройки запускайте `start.bat`.

## 3. Linux или VPS

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/setup.py
.venv/bin/python -m auto_telegram_emoji
```

Для остановки нажмите Ctrl+C. Для постоянной работы настройте службу, используя пример `scripts/auto-telegram-emoji.service` и свой путь к проекту.

## 4. Telegram

Откройте созданного вами бота и нажмите «Запустить». Это требуется владельцу один раз. Покупателю запускать этого бота не нужно.

Панель доступна только указанному Telegram ID в личном чате. Кнопка «Созданные паки» открывает историю наборов.

## 5. Тарифы

Метка должна быть уникальной, например `!gemoji_15`. Укажите 15 в поле количества и вашу цену продавца за один набор. Цена продавца означает сумму, которая поступает вам после комиссии покупки, до вывода.

В конце описания лота добавьте эту же метку отдельной строкой. После метки ничего не пишите.

Одна единица покупки даёт один набор. Две единицы тарифа по 15 дают 30 эмодзи. В одном заказе допускается до 200.

Проверяйте настройки командой:

```bash
.venv/bin/python -m auto_telegram_emoji --check
```

На Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

## 6. HTTPS

Встроенный сервер работает на `127.0.0.1:8206`. Пример Caddy:

```text
emoji.example.com {
    reverse_proxy 127.0.0.1:8206
}
```

Укажите свой домен вместо `emoji.example.com`. В `.env` значение `PUBLIC_BASE_URL` должно быть `https://ваш.домен` без дополнительного пути. DNS должен вести на сервер с прокси.

## 7. Первый запуск

Количество вариантов в тарифе не должно превышать число шаблонов в каталоге.

Папку `data` и файл `.env` не загружайте в публичный репозиторий.
