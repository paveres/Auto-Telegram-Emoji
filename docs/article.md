# Auto Telegram Emoji

Самостоятельный бот для изготовления именных эмодзи по заказам FunPay. Работает на Windows или Linux. Покупатель выбирает варианты, задаёт тексты и получает ссылку на готовый набор в Telegram.

Программа предназначена для автоматизации недорогих заказов и получения отзывов от реальных покупателей. Может стать источником дополнительного заработка. Доход зависит от спроса, цен и расходов.

## Возможности

Можно собирать эмодзи из разных коллекций и вводить отдельный текст для каждого. Доступны шрифты, цвета, градиенты, размер и расположение надписи.

Перед созданием покупатель видит предпросмотр и выбирает набор стикеров или набор эмодзи. Программа сохраняет этап заказа и историю готовых наборов.

В вашем Telegram боте есть закрытая панель с созданными паками. Покупателям она недоступна. Вся переписка по заказу остаётся на FunPay.

## Что понадобится

Python 3.11, аккаунт FunPay со счётом в рублях, golden_key, Telegram бот от @BotFather и ваш числовой Telegram ID.

Для показа анимации нужен публичный HTTPS адрес. Программа должна оставаться запущенной. Если выключить компьютер, обработка заказов остановится.

## Установка на Windows

1. Скачайте архив проекта и распакуйте его в отдельную папку.

2. Установите Python 3.11 и запустите install.bat.

3. Дождитесь установки библиотек. Мастер попросит данные FunPay, Telegram бота и адрес предпросмотра.

4. Добавьте тарифы и свои шаблоны.

5. Откройте своего Telegram бота и нажмите «Запустить».

6. Для обычного запуска используйте start.bat.

## Установка на Linux или VPS

В папке проекта выполните:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/setup.py
.venv/bin/python -m auto_telegram_emoji
```

В папке scripts есть пример службы для постоянной работы. Настройка HTTPS описана в docs/install.md.

## Привязка лотов

В мастере задайте метку, количество эмодзи и цену продавца за один набор. Например, для 15 эмодзи можно использовать такую метку:

```text
!gemoji_15
```

Добавьте её отдельной последней строкой в описание нужного лота. Название и остальной текст можно оформить самостоятельно.

Цена продавца означает сумму, которая поступает вам за одну единицу покупки. Две единицы тарифа по 15 дадут покупателю 30 эмодзи. Общий лимит заказа составляет 200.

## Шаблоны

В проекте семь коллекций и 158 шаблонов. В каждой не больше 25 вариантов. Собственные коллекции можно подключить через мастер.

Нужны подготовленные TGS с размеченными контурами надписи. Произвольная анимация без разметки для замены текста не подойдёт. Пример и описание формата находятся в docs/templates.md.

## Как проходит покупка

1. Покупатель оплачивает лот. Бот отправляет напоминание и показывает коллекции.

2. Покупатель собирает набор. После выбора бот показывает все изображения с номерами.

3. Покупатель вводит номер и текст для этого эмодзи. Знак минус оставляет надпись без изменения.

4. После оформления покупатель проверяет предпросмотр и выбирает тип пака.

5. Бот создаёт пак, отправляет ссылку и предлагает проверить результат перед подтверждением заказа.

Для использования пользовательских эмодзи нужен Telegram Premium. Стикеры можно использовать без него.

## Команды

Список открывается сообщением «Получить команды» или командой !команды.

Каталог и помощь доступны до покупки. Настройки открываются для своего оплаченного или бонусного набора. Команда !мои показывает историю, а !пак повторяет ссылку на результат.

## Перед началом продаж

Пройдите сценарий на своём тестовом заказе. Проверьте оплату, картинки, тексты, создание пака и повторную выдачу.

Данные доступа хранятся в .env, рабочие заказы и импортированные коллекции находятся в data. Не загружайте эти файлы в публичный репозиторий.
