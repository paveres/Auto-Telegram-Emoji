# Auto Telegram Emoji

Самостоятельная программа для создания именных эмодзи по заказам FunPay.

Покупатель выбирает изображения, вводит текст для каждого и получает ссылку на созданный набор стикеров или эмодзи.

Программа предназначена для автоматизации недорогих заказов и получения отзывов от реальных покупателей. Может стать источником дополнительного заработка. Доход зависит от спроса, цен и расходов.

## Возможности

Выбор из разных коллекций, отдельные тексты, шрифты, цвета, градиенты и расположение надписи. Перед выдачей бот показывает результат и предлагает выбрать тип набора.

Заказы сохраняются в SQLite. Есть очередь обработки, защита от ранних ответов, повторная выдача через `!мои` и закрытая панель владельца в Telegram.

## Структура

```text
auto_telegram_emoji/    Программа и сценарий заказа
FunPayAPI/             Библиотека подключения к FunPay
assets/                Коллекции и шрифты с лицензиями
config/                Пример тарифов
scripts/               Настройка и сборка архива
docs/                  Инструкции и статья
third_party/           Происхождение сторонней библиотеки
data/                  Рабочие файлы, создаются при запуске
```

## Быстрый запуск на Windows

Установите Python 3.11. Запустите `install.bat`, пройдите мастер настройки, затем откройте `start.bat`.

## Быстрый запуск на Linux

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/setup.py
.venv/bin/python -m auto_telegram_emoji
```

## Привязка лота

В мастере задайте метку, размер набора и цену продавца. Добавьте метку отдельной последней строкой в описание лота.

```text
!gemoji_15
```

Этот пример означает ваш тариф с 15 эмодзи. Число в метке само по себе ничего не меняет: количество берётся из настроек тарифа.

Название и оформление лота свободные. Программа проверяет оплату, продавца, сумму и метку. Поддерживается счёт продавца в рублях, не больше 200 эмодзи в одном заказе.

## Шаблоны

В каждой коллекции 25 TGS. Собственные коллекции импортируются мастером и сохраняются в `data/assets`.

Редактируемые векторные контуры текста в TGS должны иметь имена с префиксом `emoji_glyph:`. Произвольный TGS без разметки не подходит для замены надписи. Подробнее в [инструкции по шаблонам](docs/templates.md).

## Данные доступа

Мастер сохраняет секреты в `.env`. Рабочие заказы, импортированные шаблоны и архивы находятся в `data`. Эти файлы не входят в релизный архив и исключены из Git.

Не запускайте несколько программ автоматизации на одном аккаунте FunPay одновременно.
