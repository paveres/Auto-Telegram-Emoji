# Демоколлекция

Три простых шаблона созданы для Auto Telegram Emoji и распространяются на условиях лицензии проекта. Шрифты Google Fonts сопровождаются собственными OFL-лицензиями в fonts. Свои коллекции импортируйте через мастер: они сохраняются в data/assets и не включаются в публичный архив.
